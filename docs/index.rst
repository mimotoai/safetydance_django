==================
safetydance_django
==================

**safetydance_django** provides Django and Django REST framework test steps
for `safetydance`_, such as ``Given.http.get(...)`` and
``Then.http.status_code_is(200)``. Import ``Given``, ``When``, ``Then``,
``And``, ``test_context`` and ``Http`` from ``safetydance_django.test``.

.. _safetydance: https://pypi.org/project/safetydance/
